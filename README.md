# elevator-sim
A simulator that visually demonstrates optimal elevator algorithms with a GUI, made using **Qt Creator 5.15** in **Linux/Ubuntu**. It contains 3 elevators, and 3 passengers that you can control to enter/exit elevators, request elevators from a floor, and request floors within the elevator. Additionally, the simulator can also demonstrate scenarios such as a fire emergency, an obstacle blocking the elevator doors, and elevator weight overload.

## How to Run Application
1. Open the project in Qt Creator 5 in Linux/Ubuntu
2. Run `Build > Run qmake`
3. Start the app

OR

1. Run `build-elevator-sim-Desktop-Release/app/app`


## How to Run Tests
1. Open the project in Qt Creator 5 in Linux/Ubuntu
2. Run `Tools > Tests > Run All Tests`
